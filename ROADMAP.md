# Roadmap

- Publish to npm, so `npx -y ladoo-mcp` works without building from GitHub, and list the server in the MCP registry (`server.json` is ready).
- A Claude Desktop extension (`.mcpb`) for one-click install.
- OAuth sign-in for the hosted HTTP mode, so remote clients don't need an API key.
- Tools for blocked callers and agent tests, if people ask for them.
